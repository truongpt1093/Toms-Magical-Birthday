# 🎂 TOM'S MAGICAL BIRTHDAY – SINH NHẬT DIỆU KỲ CỦA TÔM 🧸🎈

Món quà sinh nhật 3D trực tuyến đặc biệt dành riêng cho bé **Phạm Hoàng Minh Trí (nickname: Tom)**, sinh ngày **13/11/2025**.

Trò chơi tái hiện một hoa viên sinh nhật rực rỡ sắc màu, phong cách 3D Pastel Chibi ấm áp. Người chơi có thể tự do dạo chơi, giao lưu cùng khách mời AI tí hon, tham gia 5 hoạt động sinh nhật và cùng Tôm thổi nến chúc mừng tuổi mới!

---

## ✨ Điểm nổi bật kỹ thuật

- **Một file duy nhất:** Toàn bộ game gói gọn trong file `index.html`.
- **Zero Assets File:** 100% hình khối 3D tạo bằng Three.js Geometries; texture khuôn mặt, hoa cỏ, thảm đỏ sinh bằng Canvas 2D; âm thanh tổng hợp 100% qua Web Audio API (không tải bất kỳ ảnh, model hay file âm thanh nào từ bên ngoài).
- **Thiết bị hỗ trợ:** Tối ưu hóa đặc biệt cho màn hình dọc điện thoại (Virtual Joystick) và máy tính bàn (WASD / Mũi tên + Chuột).
- **Lưu trữ dữ liệu:** Lưu trữ an toàn trên thiết bị người dùng qua `localStorage`.
- **Xuất ảnh kỷ niệm:** Tạo thiệp dọc độ phân giải cao 1080×1350 với snapshot 3D thực tế, hỗ trợ Web Share API hoặc tải trực tiếp PNG.

---

## 🎮 Các khu vực & Hoạt động trong game

1. **Cổng chào sinh nhật:** Vòm pastel, chữ nổi *HAPPY BIRTHDAY TOM*, thảm đỏ dẫn vào sân tiệc.
2. **Sân tiệc & Gấu Teddy khổng lồ:** Bàn tiệc tròn, dây đèn fairy light đung đưa, chú gấu Teddy khổng lồ cao 3.8m ôm trái tim *"TOM 1 TUỔI - 13/11/2025"*.
3. **Sân khấu sinh nhật (Thổi nến):** Bánh kem đa tầng phát sáng, bé Tôm đứng cạnh bánh. Nhấn giữ hoặc chạm để thổi tắt nến, pháo hoa giấy bùng nổ và khúc ca *Happy Birthday* vang lên!
4. **Khu bàn quà bí mật:** Mở 6 hộp quà với những bất ngờ 3D (Gấu Teddy, xe hơi, tháp xếp hình, chùm bóng bay, ngôi sao nhỏ, vương miện hoàng tử) kèm lời chúc ấm áp.
5. **Khu vui chơi (Playground):** Nhà bóng pastel, cầu trượt, bập bênh, khối xếp hình T-O-M và mini-game hứng bóng bay 30 giây rộn ràng.
6. **Khu chụp ảnh & Hòm thư sinh nhật:** Chụp ảnh kỷ niệm với chữ *ONE* mạ vàng, gửi lời chúc qua bóng bay lời chúc hoặc hộp thư sinh nhật.
7. **Sổ lưu niệm (Scrapbook):** Xem lại toàn bộ thành tích, quà đã mở và các lời chúc yêu thương đã gửi tặng bé Tôm.

## 🚀 Hướng dẫn mở và triển khai

### Mở trực tiếp
Bạn chỉ cần mở trực tiếp file `index.html` bằng bất kỳ trình duyệt nào (Google Chrome, Microsoft Edge, Safari).

### Chạy local server (tùy chọn)
```bash
npx serve .
# Hoặc
python -m http.server 8080
```

### Triển khai lên mạng (Vercel / GitHub Pages / Netlify)
Chỉ cần kéo thả thư mục dự án hoặc push lên GitHub và kết nối với Vercel / Netlify là trang web có thể truy cập toàn cầu ngay lập tức!
